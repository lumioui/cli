# Security

Please don't open a public issue for a security problem. Use GitHub's private vulnerability reporting instead (the Security tab, then "Report a vulnerability"), or email hello@lumioui.com with "Security" in the subject.

Include what you found, how to reproduce it and which CLI version you used. We'll reply within a few working days and credit you in the fix unless you'd rather stay anonymous.

Things we especially want to hear about:
- a way to make the CLI send a licence key anywhere other than the default registry or the user's own `LUMIO_REGISTRY`;
- writing files outside the project folder;
- running code from a registry response.
